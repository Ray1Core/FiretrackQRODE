' ----- CONNECTIONS (all shapes are now linked!) -----

' 1. roles ↔ users
roles -1- Has
Has -N- users

' 2. users ↔ equipment via Requests (many-to-many)
users -N- Requests
Requests -N- equipment

' 3. equipment ↔ users via Assigns (many-to-many)
equipment -N- Assigns
Assigns -N- users

' 4. handshakes – from_user
users -1- HandshakeFrom
HandshakeFrom -N- handshakes

' 5. handshakes – to_user
users -1- HandshakeTo
HandshakeTo -N- handshakes

' 6. handshakes – equipment
equipment -1- HandshakeEquip
HandshakeEquip -N- handshakes

' 7. damage_reports – reported_by
users -1- DamageReported

' 8. damage_reports – equipment

' 10. disposal_requests – equipment

DisposalEquip -N- disposal_requests

' 11. notifications – user

' 12. ics_documents – equipment
